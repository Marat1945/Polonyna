POLONYNA — ИСПРАВЛЕНИЕ V3 (версия 0.2.1)
=========================================

ПОЧЕМУ ПАДАЛА СБОРКА (шаг "Build debug APK")
1. В репозитории лежали ДВЕ копии кода: старая app/src/main/java/com/lanmora/...
   и новая app/src/main/java/com/polonyna/... Старая ссылается на com.lanmora.app.R,
   которого больше нет (namespace = com.polonyna.app) -> ~40 ошибок "Unresolved reference R".
   Причина: загрузка через браузер (Add files via upload) НЕ удаляет старые файлы.
   ИСПРАВЛЕНО: папки com/lanmora в этом комплекте нет.
2. LanmoraUi.kt: import android.media.MediaController — такого класса в Android нет.
   ИСПРАВЛЕНО: import android.widget.MediaController.
3. build.gradle.kts: плагин Compose был 2.2.10, а AGP 9.2 подтягивает более новый Kotlin.
   ИСПРАВЛЕНО: Kotlin 2.3.21 задан явно и одинаково для Kotlin и Compose; AGP 9.2.1.

ИСПРАВЛЕННЫЕ ОШИБКИ В РАБОТЕ ПРИЛОЖЕНИЯ
- Звонки: после одной неудачной попытки все следующие звонки были без звука до перезапуска.
- Громкая связь: не хватало разрешения MODIFY_AUDIO_SETTINGS (кнопка «Динамик» не работала).
- Аудиосообщения: слишком короткая запись создавала битый файл, который «ронял» приложение.
- Видеокружок: превью камеры было квадратным; крестик во время записи отправлял видео.
- Устройство могло увидеть в списке само себя.
- Язык интерфейса сбрасывался после перезапуска на Android 6–12.
- Подпись "Audio" в сообщении теперь на 4 языках.

КАК ЗАГРУЗИТЬ
Вариант А (проще всего): распаковать ZIP, запустить 1_UPLOAD_TO_GITHUB.bat, ввести YES.
  Скрипт заменит ветку main содержимым папки — папка com/lanmora исчезнет сама.
Вариант Б (через браузер):
  1) На GitHub открыть app/src/main/java/com/ -> папка lanmora -> «...» -> Delete directory -> Commit.
  2) Add file -> Upload files -> перетащить содержимое распакованной папки -> Commit.

ВАЖНО ПРИ УСТАНОВКЕ APK
Каждая сборка GitHub Actions подписана новым временным debug-ключом,
поэтому новую версию поверх старой Android не установит («Приложение не установлено»).
Перед установкой удалите предыдущую версию Polonyna с телефона.
