ПОЛОНИНА ДЛЯ ПК (Windows) — версия 0.4.0
=========================================

1. СБОРКА EXE НА GITHUB
   • Залейте содержимое папки в репозиторий Polonyna-PC (1_UPLOAD_TO_GITHUB.bat или Add file → Upload files,
     обязательно вместе с папкой .github). Через браузер старые файлы не удаляются — лишние сотрите вручную.
   • Actions → «Build Windows EXE» → зелёная галочка → Artifacts → Polonyna-Windows:
     Polonyna-Setup-0.4.0.exe (установщик) и Polonyna-Portable-0.4.0.exe.
   • Для постоянной работы ставьте Setup. Portable не запускайте второй раз, пока он уже открыт.

2. ПЕРВЫЙ ЗАПУСК
   • «Windows защитила ваш компьютер» → «Подробнее» → «Выполнить в любом случае».
   • Брандмауэр → «Частные сети» → «Разрешить доступ». Сеть в Windows должна быть «Частной».

3. ЧТО НОВОГО (0.3 + 0.4)
   • Окно больше не пропадает: кнопка ✕ только сворачивает программу, значок остаётся внизу на панели задач.
     Выйти совсем: меню ⋮ → «Вийти з програми». Если интерфейс аварийно упадёт — программа сама его перезапустит.
   • Заставка на прозрачном фоне. Нажатие на логотип вверху показывает её ещё раз поверх программы.
   • Новое фото, имя, название устройства собеседника видно сразу (меньше секунды); кроме того, программа
     каждые 6 секунд сверяет профили и догружает то, что не дошло.
   • Звуки: стандартные — ваши mp3 (сообщение, звонок, видеозвонок). Поменять: Налаштування → Сповіщення
     (или карточка «Звуки і мелодії» в настройках) → «Обрати свою…», ▶ — прослушать, «Скинути» — вернуть стандартную.
   • Видеозвонок: кнопка с камерой рядом с трубкой. Во время звонка — Мікрофон, Камера, Завершити.
   • «Видалити у всіх» (правый клик по сообщению). Если собеседник не в сети — удалится, когда он появится.
   • Правый клик по файлу: Копіювати, Вставити, Переслати, Зберегти як…, Відкрити, Показати в папці.
   • Налаштування → «Камера і мікрофон»: выбор устройств и «Перевірити». Программа сама берёт работающие.

4. ЕСЛИ НЕ ВИДНО КАМЕРУ ИЛИ МИКРОФОН
   Налаштування → «Камера і мікрофон» → строка «Windows показує мікрофонів: …, камер: …».
   0 — Windows не даёт устройства программам: кнопки «Доступ до камери/мікрофона в Windows» → включите доступ
   и «Разрешить классическим приложениям». Проверьте шторку камеры и F-клавиши с перечёркнутым значком.

5. ЕСЛИ ЧТО-ТО ПОШЛО НЕ ТАК
   Налаштування → Про програму → «Журнал роботи» — пришлите файл polonyna.log.
