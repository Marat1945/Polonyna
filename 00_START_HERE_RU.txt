КАК ЗАЛИТЬ В GITHUB
===================

ВАРИАНТ 1 — НОВЫЙ РЕПОЗИТОРИЙ (САМЫЙ ЧИСТЫЙ)
1. Распакуйте Polonyna_FULL_READY_GITHUB.zip.
2. Откройте папку Polonyna_FULL_GITHUB.
3. В GitHub создайте новый пустой repository.
4. Нажмите "uploading an existing file" / Add file → Upload files.
5. Выделите ВСЁ содержимое папки Polonyna_FULL_GITHUB.
6. Перетащите в GitHub.
7. Проверьте, что в репозитории появилась папка .github.
8. Commit changes.
9. Откройте Actions → Build Android APK.
10. Дождитесь сборки.

ВАРИАНТ 2 — СУЩЕСТВУЮЩИЙ РЕПОЗИТОРИЙ
Лучше удалить старый репозиторий и загрузить этот комплект заново, чтобы не осталось
старых файлов. Если не хотите удалять, содержимое архива должно заменить старые файлы.

ВАЖНО
=====
Файл workflow уже лежит по правильному пути:
.github/workflows/android.yml

На Windows папка .github может выглядеть как обычная папка с точкой в начале.
Не пропускайте её при загрузке.

После успешной сборки:
Actions → завершённый запуск → Artifacts → Polonyna-debug-apk → скачать ZIP →
внутри будет app-debug.apk.
